# Introduction to Deep Learning for Computer Vision Repo
## hotdogornot

CNN to say if an image contain an HotDog or not

To get started copy and run the following script to set up the environment:
```bash
conda env create --file environment.yml --name DEEPLCV
```
Activate the environment:
```bash
conda activate DEEPLCV
```
> **⚠️ Warning:**  
> Training and testing data should be added to `data/hotdog_nothotdog`.
